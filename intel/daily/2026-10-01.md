### 1. Hybrid Gaussians for Robust Open-Vocabulary 3D Segmentation with Multi-View Object Association and Boundary Refinement【摘要+部分章节】
- 链接：https://arxiv.org/abs/2609.27462 （PDF：https://arxiv.org/pdf/2609.27462）
- 提交日期：2026-09-23（cs.CV；arxiv abs 页 citation_date=2026/09/23）
- 作者：Xueqi Qiu, Yueming Sun, Tianyu Zhang, Yuxuan Xia, Yang Long（Durham University；上海交通大学）
- **方向归属**：② 开放词汇和大模型驱动的语义地图（开放词汇 3D 分割 + 3DGS 语言对齐语义；非在线 SLAM 系统）。
- **要解决的问题**：真实多视角序列中，不完整/噪声 2D 监督使跨视角物体身份不稳定；全场景语义学习又削弱物体级可分性；边界处 2D→3D 提升易漏边、串类。
- **方法**：Hybrid Gaussians——每个高斯同时带物体身份 `zn` 与可学习语言对齐嵌入 `fn`。Multi-View Object Association：Observation Fusion（跨视角软融合物体证据并做物体条件渲染）+ Semantic Contrastive Learning（物体条件语义渲染 + 跨视角对比对齐，CLIP 空间特征作参考）。Boundary Reconstruction Optimization（BRO）在轮廓邻域对齐渲染梯度与掩码观测。2D 掩码由 SAM 初始化、SAM2 跨视角传播。实验在 NVIDIA RTX 4090。
- **实验数据**：LERF、3D-OVS；对比 LERF / LEGaussians / LangSplat / OpenGaussian / Seg-Splat / Laser / SAGA / COS3D 等。
- **作者自报关键数字**（对照 PDF 表 1–3 与摘要）：
  - 表 1（平均 mIoU %）：Ours **LERF 59.1**、**3D-OVS 96.1**；同表第二好大致为 Laser 53.0（LERF）、SAGA 96.0（3D-OVS）。摘要称相对基线 LERF 上 **13.4% 相对增益**（与表 1 中 Seg-Splat 52.1 → 59.1 的相对增幅一致）；正文称相对第二好分别高 **7.0 / 0.1** 个点。
  - 表 3 消融（mAcc / mIoU / mBIoU）：全模块 **LERF 84.36 / 59.13 / 60.54**，**3D-OVS 98.59 / 96.12 / 88.27**；去掉任一模块均下降（如无 OF/SCL/BRO 基线 LERF mIoU 52.15）。
  - 表 2（Train ms/iter / Infer ms/iter / 峰值显存 MB）：Ours LERF **75.99 / 278.56 / 3721.02**，3D-OVS **38.98 / 108.92 / 2903.34**；正文称相对 OpenGaussian 训练时间分别少约 **10.4% / 15.7%**，但推理与显存更高。
- **作者承认的局限 / 边界**：正文效率段承认额外推理与显存开销；文中未见独立 Limitations 小节。项目页：https://nora202.github.io/hybridgaussians/ （本日可打开）。
- **阅读说明**：已下载 PDF + pdftotext；读了摘要、方法 2.1–2.3、表 1–3、实验结果与结论相关段落；未通读全部参考文献细节与全部定性图说明。

### 2. Know-Your-Scene (KYS)-SLAM: Hierarchical Semantic-Motion Priors for Feature Matching in Stereo Visual SLAM【摘要+部分章节】
- 链接：https://arxiv.org/abs/2609.27509 （PDF：https://arxiv.org/pdf/2609.27509）
- 提交日期：2026-09-23（cs.CV / cs.RO；citation_date=2026/09/23）
- 作者：Preeti Chatterjee, Jin Lu, Jin Sun, Suchendra M. Bhandarkar（University of Georgia）
- **方向归属**：① 语义 SLAM 与三维重建（语义/全景/运动先验调制立体特征匹配的 ORB-SLAM3 扩展）。**说明**：主贡献是用语义先验改善**几何跟踪/定位**，不是开放词汇语义建图；与“语义地图”有明确关联但不等同。
- **要解决的问题**：局部描述子立体 SLAM 受语义歧义、同实例混淆与独立运动物体破坏数据关联；既有语义/动态 SLAM 多用**二值剔除**特征，牺牲对应密度与 BA 几何支撑。
- **方法**：在 ORB-SLAM3 匹配阶段做连续对应代价调制（几何后端不变）：语义类 + 时序一致实例身份 + 深度补偿尺度代理，按同实例/跨实例/跨类分层缩放描述子距离；零样本运动模块用深度感知 ego-motion 拟合背景光流，经自校准阈值对有足够运动证据的 panoptic 段降权。全套系数**跨序列/数据集固定不重调**。评测排除 EuRoC V203（立体帧数未对齐）。硬件叙述含 NVIDIA RTX A6000。
- **实验数据**：KITTI Odometry 11 条、EuRoC 10 条；动态子集 KITTI Tracking、Virtual KITTI 2；对比 ORB-SLAM3/2、DynaSLAM、RSO-SLAM、Semantic I/II、DROID-SLAM\*、DVI-SLAM 等。
- **作者自报关键数字**（对照 PDF 表 1/2/5 与结论）：
  - 表 1：相对 ORB-SLAM3，KYS-SLAM 平均每序列 ATE **↓17.4%**；动态代表序列 Dyn. **↓22.9%**（+Pano 骨干 16.6% / 17.7%）。例：Seq.02\* 5.68→4.46 m；Seq.08\* 3.72→3.12 m；Seq.10\* 1.32→0.91 m。正文称 21 条序列**无相对 ORB-SLAM3 的回退**。
  - 表 2：EuRoC 平均 ATE ORB-SLAM3 **0.040** → KYS-SLAM **0.028**（摘要/结论：**↓27.7%**）；+Pano 亦为 0.028。
  - 表 5 动态子集：KITTI Tracking / Virtual KITTI 2 平均每序列 ATE 分别 **↓6.6% / ↓17.8%**，Virtual KITTI 2 Sc.01 可达 **↓31.2%**（0.240→0.165 m）。
  - 运行：调制相对 ORB-SLAM3 跟踪约 **+6.8–8.2 ms/帧**、峰值主机内存约 **+0.22–0.52 GB**；先验离线生成约 **1696 ms/帧**（正文：系统整体未针对实时优化，与多数预计算语义 SLAM 类似）。
- **作者承认的局限 / 边界**：运动检测受远距慢速目标与小段噪声限制；Seq.00/01 上运动模块相对纯 panoptic 骨干有回退但仍优于 ORB-SLAM3；未来工作指向在线先验、学习特征与端到端部署。
- **阅读说明**：已下载 PDF + pdftotext；读了摘要、引言贡献、表 1/2/5、运行开销与结论；未逐格核对补充表 S1–S7 全部消融。

### 3. Towards robust multimodal 3D object detection via visual foundation models（RoboDistill）【摘要+部分章节】
- 链接：https://arxiv.org/abs/2609.23541 （PDF：https://arxiv.org/pdf/2609.23541）
- 提交日期：2026-09-20（cs.CV / cs.RO；citation_date=2026/09/20）
- 作者：Ziying Song, Lin Liu, Hongyu Pan, Shaoqing Xu, Lei Yang, Mingzhe Guo, Caiyan Jia（北京交通大学；地平线；澳门大学；南洋理工大学）
- **方向归属**：③ 多传感器融合感知（LiDAR–相机多模态 3D 检测；VFM/SAM 引导的鲁棒融合与蒸馏）。
- **要解决的问题**：多模态 3D 检测在干净基准上强，但在传感器噪声、恶劣天气等 **OOD**（KITTI-C / nuScenes-C，共 27 类扰动）下易崩。
- **方法**：RoboDistill——(1) **SAM-AD**：在自动驾驶图像上微调 SAM，预训练覆盖 Robustness3D 噪声类型；(2) **AD-FPN** 多尺度上采样 SAM 特征以与 LiDAR 融合；(3) **DGWA**（Depth-Guided Wavelet Attention）抑高频噪声；(4) **KD Fusion**：预训练 SAM-AD 作教师，向轻量点云网络蒸馏。变体 L/B/T 分别用 SAM / FastSAM / MobileSAM。KITTI 以 Focals Conv 为骨干；nuScenes 以 TransFusion 设定为参照。训练/评测叙述含 8× NVIDIA A100。
- **实验数据**：KITTI / nuScenes 干净集；KITTI-C / nuScenes-C 共 27 类 OOD；对比 LoGoNet、BEVFusion-mit、SparseFusion、CMT、RoboFusion（前代）等。
- **作者自报关键数字**（对照 PDF 表 1–3、图 1、结论）：
  - 表 1（KITTI car AP3D R40）：RoboDistill(L) 验证集 **mAP 89.03**（Easy/Mod/Hard 93.55 / 88.11 / 85.44），测试集 **86.13**（92.52 / 84.65 / 81.21）；高于表内 LoGoNet 验证 87.13 / 测试 85.87。
  - 表 2（nuScenes）：(L) 验证 **NDS 72.7 / mAP 70.5**，测试 **73.4 / 71.3**；相对 BEVFusion-mit 验证 NDS/mAP **+1.3 / +2.0**；模型约 **100.31M**、**3.0 FPS**（A100，448×800，FP16）。(T) 约 **15.23M / 5.8 FPS**。
  - 表 3（severity）；nuScenes-C 天气例：(L) Snow/Rain/Fog mAP **69.00 / 68.77 / 68.00**（相对 RoboFusion 约 +1.88 / +1.19 / +0.99）。KITTI-C 天气：(L) 相对 RoboFusion 雪/雨/雾/强光 AP 约 **+0.21 / +0.33 / +0.29 / +0.37**。
  - 图 1 叙述：示意雾+雪扰动下 car moderate AP **86.71% vs LoGoNet 62.58%（+24.13 点）**（作者自报示意对比，非表 3 全扰动均值）。
- **作者承认的局限**：强依赖 VFM 表征、模型更复杂；(L)/(B) 推理偏慢；未来拟训练期用 SAM、部署期轻量学生，并扩展更真实噪声。
- **阅读说明**：已下载 PDF + pdftotext；读了英文摘要、方法要点、表 1–3、结论与 Limitations；未通读中文平行章节与表 4–7 全部格子。
