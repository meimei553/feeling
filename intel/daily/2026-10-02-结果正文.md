### 1. Dual Covariance Gaussian Splatting SLAM: Decoupling Rendering and Registration for Robust Real-Time Tracking【摘要+部分章节】
- 链接：https://arxiv.org/abs/2609.25746 （PDF：https://arxiv.org/pdf/2609.25746）
- 学科类别（arXiv 页面）：主类 cs.RO，交叉 cs.CV；当前仅 v1（2026-09-22 提交）
- 提交日期：2026-09-22（cs；arxiv abs 页 citation_date=2026/09/22）
- 作者：Edward Beng Wai Tan, Siew-Kei Lam（Nanyang Technological University）
- **方向归属**：① 语义 SLAM 与三维重建（稠密 3DGS SLAM 跟踪/建图；**非**语义开放词汇建图，主贡献是双协方差解耦渲染与配准以增强几何跟踪）。
- **要解决的问题**：ICP 式 3DGS SLAM 把同一高斯协方差既用于光度渲染又用于配准；映射器为降光度误差常把协方差压扁贴表面，与传感器测量不确定性方向冲突，弱结构/无纹理场景可观测性差、漂移大。
- **方法**：双协方差参数化——每个高斯共享均值，但保留渲染协方差 Σ_r（映射器优化）与跟踪协方差 Σ_t（由 RGB-D 传感器噪声模型推导）。深度残差用 G-ICP + Σ_t；图像残差将 KLT 角点锚定到高斯切平面以补切向可观测性。位姿由深度+图像联合代价经 LM 求解。评测硬件叙述含 i9-13900KF + RTX 4090。
- **实验数据**：TUM RGB-D、ScanNet、Replica；另录两条 RealSense D435i 户外轮式/手持序列；对比 GS-ICP SLAM、SGAD-SLAM、Spectral GS-SLAM、Photo-SLAM、MonoGS、SplaTAM、ORB-SLAM3 等。
- **作者自报关键数字**（对照 PDF 表 I–VIII 与 Limitations）：
  - 表 I（标准 TUM，ATE cm，† 限 30 FPS）：Ours **1.94 / 1.55 / 2.23**，avg **1.91**，uncapped FPS **59.1**；同表 Coupled 中 SGAD-SLAM avg 2.0 / 20.4 FPS，GS-ICP † avg 2.4。
  - 表 II 扩展 TUM：Ours avg ATE **7.12** cm（ORB-SLAM3 5.35；GS-ICP 13.30；Spectral 11.06）。
  - 表 III 无结构/无纹理：nos_tex_near Ours **1.67** cm（GS-ICP / SGAD ~195）；s_notex_far **4.93**。
  - 表 IV ScanNet avg ATE：**9.61** cm（ORB-SLAM3 18.2；SplaTAM 11.9）。
  - 表 V Replica avg ATE：**0.20** cm（略逊于 G2S-ICP / GS-ICP 的 0.15/0.16；作者称仿真无深度噪声时噪声地板使性能略降）。
  - 表 VI（1 s RPE）：Ours 平移/旋转 avg **4.05 cm / 2.20°**（ICP 系中最低量级之一）。
  - 表 VII 渲染 avg：Ours PSNR **21.39**、SSIM **0.784**、LPIPS **0.219**（实时方法中 SSIM/LPIPS 最优段）。
  - 表 VIII 消融：Full 在 fr1/desk **1.94**、fr3/nos_tex **1.67**；Shared cov 基线 nos_tex **194.96**。
- **作者承认的局限 / 边界**：缺 BA，大场景长期一致性有限；对远距高深度误差敏感；未来拟用路标/协方差做 BA 且尽量不牺牲速度。未见已核实官方代码 URL。
- **阅读程度**：【摘要+部分章节】，非全文。实际读了：摘要、第 III 节方法、表 I–VIII（含表 V、VI、VII、VIII）、Limitations 与结论；未通读引言与相关工作、参考文献和全部定性图说明。

### 2. OpenGaFF: Open-Vocabulary Gaussian Feature Field with Codebook Attention【摘要+部分章节】
- 链接：https://arxiv.org/abs/2605.06088 （PDF：https://arxiv.org/pdf/2605.06088）
- 提交日期：2026-05-07（arXiv 页面学科类别 cs.CV；页面现为 v3，v3 提交于 2026-05-22，本稿数字所依据的版本未逐版比对；较早的论文，已注明真实日期；9 月新提交中可核实的开放词汇 3DGS 论文偏少，故收录）
- 作者：Kunyi Li, Michael Niemeyer, Sen Wang, Stefano Gasperini, Nassir Navab, Federico Tombari（TUM / MCML / Google / Visualais）
- **方向归属**：② 开放词汇和大模型驱动的语义地图（开放词汇 3DGS 特征场 + 结构化语言 codebook；离线场景理解，非在线 SLAM）。
- **要解决的问题**：多视角开放词汇 3D 语义碎片化、几何–语义弱耦合；压缩解码丢细粒度语言信息；固定大小 codebook 难适配场景复杂度。
- **方法**：OpenGaFF——(1) Gaussian Feature Field：以高斯位置/外观为条件预测低维语义特征，强化几何一致性；(2) 数据驱动 k-means 初始化 Structured Language Codebook；(3) codebook-guided attention 从共享原语检索高维语言特征；另设独立语义不透明度。两阶段训练（LD 蒸馏 + 语言/熵正则）。硬件叙述含单卡 RTX 4090。
- **实验数据**：LERF-OVS、ScanNet-v2；对比 LangSplat / LangSplatV2 / GALA / OccamLGS / Dr.Splat / OpenGaussian / VALA 等。
- **作者自报关键数字**（对照 PDF 表 1–3 与摘要）：
  - 表 1 LERF-OVS：2D mean mIoU/Acc **64.98 / 82.68**；3D mean mIoU/Acc **54.36 / 80.84**（表内 3D 明显高于 LangSplatV2 的 35.87 / 55.80、GALA 36.71 / 59.71）。
  - 表 2 ScanNet-v2：19/15/10 类 mIoU **36.55 / 42.78 / 57.85**，mAcc **50.57 / 72.85 / 77.93**（相对 VALA 19 类 mIoU 32.11）。
  - 表 3（Figurines）：Ours Memory **12 GB**、Train **15 min**、Inference **35 fps**（对照 GALA 14 GB / 200 min / 12 fps；LangSplatV2 24 GB / 45 min / 40 fps）。
- **作者承认的局限 / 边界**：附录讨论熵权重过大导致少样本物体过特化；MipNeRF360 上 2D mIoU 略低于 LangSplatV2，作者归因于小物体/稀疏观测与统一 2D–3D 约束。项目页：https://opengaff.github.io/ （可打开）。
- **阅读说明**：读了摘要、方法 3.1–3.3、表 1–3、实验 4.x 与附录局限相关段落；未通读全部附录定性图与全部参考文献。

### 3. SplatLabel: Pseudo-Labelling through 4D Gaussian Splatting【摘要+部分章节】
- 链接：https://arxiv.org/abs/2609.29836 （PDF：https://arxiv.org/pdf/2609.29836）
- 提交日期：2026-09-24（cs；citation_date=2026/09/24）
- 作者：Nitya Nanvani, Andras Palffy, Holger Caesar（Perciv AI；Delft University of Technology）
- **方向归属**：③ 多传感器融合感知（相机 + 360° LiDAR 驱动的 4DGS 伪标注与语义占用）；同时强关联 ②（SAM 3 连续软语义蒸馏，无域内 prompt 工程）。**说明**：主产出是伪标签管道，不是在线 SLAM 前端。
- **要解决的问题**：动态场景 3D 伪标注常依赖预标注 3D 框；多模型/复杂启发难稳；既有评测只在已标注子集上看精度、忽略 recall 权衡。
- **方法**：SplatLabel——显式时间流形（Dual Deformation Kernel + Gated Deformation Mask + 寿命耦合 + 时间存在激活）；Virtual Depth Maps 注入全向 LiDAR；从 2D VFM（SAM 3）直接蒸馏连续软概率；下游提取 LiDAR 分割与任意分辨率语义占用；以 AUGRC 作选择性分类式伪标签评测。场景切约 20 s 段，A40 训练叙述。
- **实验数据**：SemanticKITTI val（Seq 08）；对比 LeAP、UniLiPs、AutoOcc 等。
- **作者自报关键数字**（对照 PDF 表 I–IV 与 Limitations）：
  - 表 I：在 LeAP 召回 **65.3%** 时 mIoU **64.2**（LeAP 58.1）；在 UniLiPs 召回 **47.32%** 时 mIoU **71.6**（UniLiPs 68.3）。
  - 表 II 语义占用：Geo. IoU **47.36**、Sem. mIoU **15.56**（AutoOcc-M 41.23 / 12.76）；五随机种子 Geo/Sem 标准差作者自报 **0.066 / 0.041** 个百分点。
  - 表 III：All Points（100% recall）AUGRC **19.4**；Camera 92.0% → **19.2**；Unoccluded 62.3% → **16.1**（越低越好）。
  - 表 IV 消融：Full AUGRC / Geo / Sem **19.4 / 47.4 / 15.6**；去掉 Virtual Depth Maps Geo IoU **−15.7**；去掉 Gated Deformation Mask Geo **−12.7**、Sem **−4.3**。
  - 算力：分割/占用端到端约 **15.28 / 33.67** GPU·h；推理约 **0.28 / 4.62** s/帧（单 A40）。
- **作者承认的局限**：稠密 3DGS 高显存；依赖相机–LiDAR 同步；恶劣光照/天气下传感器退化则鲁棒性下降。未见已核实官方代码 URL。
- **阅读说明**：读了摘要、方法 III、表 I–IV、Limitations/Future Work；未逐格核对全部 per-class 列与全部定性图。
