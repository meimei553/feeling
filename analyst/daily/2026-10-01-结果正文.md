### 1. Hybrid Gaussians for Robust Open-Vocabulary 3D Segmentation with Multi-View Object Association and Boundary Refinement
- 链接：https://arxiv.org/abs/2609.27462 （项目页：https://nora202.github.io/hybridgaussians/ ）
- 提交日期：2026-09-23
- 作者单位：Durham University；上海交通大学
- 阅读程度：**全文**（正文约 5 页，无附录）
- 方向：② 主线（开放词汇 3D 分割加 3DGS 语言对齐）；① 依赖既有多视角重建设定，不是在线 SLAM；③ 无多传感器。
- 增量：每个高斯同时带物体身份与可学习的语言对齐嵌入；多视角物体关联（观测融合加语义对比学习）；轮廓邻域的边界重建优化。2D 掩码由 SAM 初始化、SAM2 跨视角传播，实验在 RTX 4090 上。
- 关键数字（作者自报，表 1 平均 mIoU %）：Ours 在 LERF 上 59.1，3D-OVS 上 96.1。LERF 上第二好是 Laser 53.0（Ours 高 6.1 点），其后 Seg-Splat 52.1、LangSplat 51.4；相对 Seg-Splat 高 7.0 点，摘要中的 13.4% 相对增益即相对 Seg-Splat。3D-OVS 上第二好是 SAGA 96.0（高 0.1 点）。
- 表 3 消融（mAcc / mIoU / mBIoU）：全模块 LERF 84.36 / 59.13 / 60.54，3D-OVS 98.59 / 96.12 / 88.27；去掉三个模块的基线 LERF mIoU 52.15。
- 表 2 效率（训练 / 推理 ms/iter / 峰值显存 MB）：LERF 75.99 / 278.56 / 3721.02，3D-OVS 38.98 / 108.92 / 2903.34；训练时间比 OpenGaussian 少约 10.4% / 15.7%，但推理与显存更高。
- 作者承认的局限：额外推理与显存开销；文中没有独立的 Limitations 小节。
- 我读到的局限：评测为离线多视角分割，不是在线建图；2D 监督依赖 SAM/SAM2；未见真实机器人实验。
- 建议精读：是（全文，② 主线）

### 2. Know-Your-Scene (KYS)-SLAM: Hierarchical Semantic-Motion Priors for Feature Matching in Stereo Visual SLAM
- 链接：https://arxiv.org/abs/2609.27509
- 提交日期：2026-09-23
- 作者单位：University of Georgia
- 阅读程度：**摘要加部分章节**（补充表 S1–S7 未逐格通读）
- 方向：① 主线（语义先验改善立体几何跟踪与定位）；不是开放词汇语义建图；③ 无额外传感器。
- 增量：在 ORB-SLAM3 匹配阶段做连续对应代价调制，几何后端不变。语义类、时序一致的实例身份、深度补偿尺度代理按同实例、跨实例、跨类分层缩放描述子距离；零样本运动模块用深度感知的自运动拟合背景光流，对运动证据充分的全景分割段降权。全套系数跨序列固定。
- 关键数字（作者自报）：相对 ORB-SLAM3，平均每序列 ATE 下降 17.4%，动态代表序列下降 22.9%；21 条序列无回退。EuRoC 平均 ATE 0.040 到 0.028（摘要称下降 27.7%，为每序列相对降幅的均值）。KITTI Tracking / Virtual KITTI 2 平均每序列 ATE 下降 6.6% / 17.8%，Virtual KITTI 2 Sc.01 为 0.240 到 0.165（下降 31.2%）。
- 运行开销：调制约增加 6.8–8.2 ms/帧，峰值主机内存约增加 0.22–0.52 GB；先验离线生成约 1696 ms/帧，整体未针对实时优化。
- 作者承认的局限：运动检测受远距慢速目标与小段噪声限制；Seq.00/01 上运动模块相对纯全景骨干有回退，但仍优于 ORB-SLAM3；未来方向为在线先验、学习特征与端到端部署。
- 我读到的局限：增益主要在定位 ATE，不直接给出稠密语义地图质量；先验离线预计算。
- 建议精读：否

### 3. Towards robust multimodal 3D object detection via visual foundation models（RoboDistill）
- 链接：https://arxiv.org/abs/2609.23541
- 提交日期：2026-09-20
- 作者单位：北京交通大学；地平线；澳门大学；南洋理工大学
- 阅读程度：**摘要加部分章节**（表 4–7 部分格子与中文平行章节未逐格通读）
- 方向：③ 主线（激光雷达与相机的多模态 3D 检测及分布外鲁棒）；非语义地图或 SLAM。
- 增量：在自动驾驶图像上微调 SAM（SAM-AD）；多尺度上采样（AD-FPN）；深度引导小波注意力抑制高频噪声（DGWA）；以 SAM-AD 为教师向点云网络蒸馏（KD Fusion）。变体 L / B / T 分别用 SAM / FastSAM / MobileSAM。
- 关键数字（作者自报）：KITTI car AP3D R40，(L) 验证 mAP 89.03、测试 86.13，高于表内 LoGoNet 的 87.13 / 85.87。nuScenes (L) 验证 NDS 72.7 / mAP 70.5，测试 73.4 / 71.3，约 100.31M 参数、3.0 FPS；(T) 约 15.23M、5.8 FPS。同表 CMT 验证 NDS 72.9、SparseFusion 72.8，所以干净 nuScenes 上 (L) 的 NDS 并非表内最高。
- 分布外：nuScenes-C 的雪 / 雨 / 雾 mAP 为 69.00 / 68.77 / 68.00，相对 RoboFusion 高 1.88 / 1.19 / 0.99；KITTI-C 天气相对 RoboFusion 约高 0.21 / 0.33 / 0.29 / 0.37。图 1 示意雾加雪下 car moderate AP 为 86.71% 对 LoGoNet 62.58%，是作者的示意对比，不是全扰动均值。
- 作者承认的局限：强依赖视觉基础模型；模型更复杂；(L) 和 (B) 推理偏慢；计划扩展到更真实的噪声。
- 我读到的局限：干净 nuScenes 上相对最强融合基线增益有限，主要卖点在合成扰动基准；扰动不是实车采集。
- 建议精读：否
