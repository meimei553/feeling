#### 1. RoSe-SLAM: Robust Semantic-Aware Gaussian Splatting SLAM from Dynamic Monocular Videos【摘要+部分章节】
- 链接：https://arxiv.org/abs/2608.29003 （PDF：https://arxiv.org/pdf/2608.29003）
- 学科类别（arXiv 页面）：主类 cs.CV，交叉 cs.AI；当前 v1
- 提交日期：2026-08-29（cs；早于近 2–3 周范围，已注明真实日期）
- 作者：Wenting Wang, Jiaxin Guo, Wenzhen Dong, Yun-Hui Liu, Charlie C.L. Wang, Yeung Yam（The Chinese University of Hong Kong / University of Manchester / CPII）
- **方向归属**：① 语义 SLAM 与三维重建（动态单目语义感知 3DGS SLAM；用 foundation model 语义特征辅助动静态分离与多视图一致，**非**开放词汇语义建图主贡献）。
- **要解决的问题**：静态场景假设下动态干扰导致跟踪失败与重建混乱；既有动态 3DGS SLAM 常依赖深度；手工语义标签难扩展；仅凭不确定性建模（如 WildGS-SLAM）在相对深度上重建质量有限。
- **方法**：RoSe-SLAM——无标定单目 RGB；(1) 时空运动掩码（长期 + 短期）结合对极几何 inlier 分离自运动与动态物体；(2) 将 2D foundation model 语义特征蒸馏到语义高斯场，做语义感知多视图一致性；(3) 全局 BA 时以遮挡为度量的关键帧选择 + 语义引导遮挡补全。跟踪损失为颜色/深度/语义项加权并乘静态掩码。评测叙述含 coarse-to-fine 位姿与伪深度先验。
- **实验数据**：动态 TUM RGB-D、Bonn RGB-D Dynamic、Wild-Mocap；对比 ORB-SLAM3、ReFusion、NICE-SLAM、Co-SLAM、ESLAM、Rodyn-SLAM、DG-SLAM、WildGS-SLAM、SplaTAM、GS-SLAM 等。
- **作者自报关键数字**（对照 PDF 表 I–V 与结论）：
  - 表 I（Bonn 重建，动态设定）：Ours Acc / Comp / Comp.Ratio avg **7.54 cm / 12.87 cm / 43.68%**（WildGS-SLAM 同表 22.12 / 29.06 / 25.83；DG-SLAM Acc 8.06、Comp.Ratio 43.67）。
  - 表 II（TUM 动态序列 ATE cm）：Ours **2.7 / 1.2 / 0.5 / 0.8**，avg **1.3**（WildGS-SLAM avg 1.5；DG-SLAM 2.2；GO-SLAM 2.05）。
  - 表 III（Wild-Mocap ATE cm）：Ours **0.3 / 0.4 / 0.4 / 0.9 / 0.3**，avg **0.46**（与 π³mos-SLAM avg 0.46 同量级；WildGS-SLAM 0.56）。
  - 表 IV 消融（ATE cm）：Full Bonn/TUM **2.9 / 1.3**；去掉长期动态掩码 **3.61 / 1.98**；去掉语义多视图一致 **3.57 / 1.65**；去掉语义引导遮挡关键帧 **3.31 / 2.1**。
  - 表 V（TUM f3/w x，不含语义分割耗时）：Tracking / Mapping **97.5 / 216.7** ms（DG-SLAM 89.2 / 549.3）。
- **作者承认的局限 / 边界**：正文未见独立 Limitations 小节；结论强调依赖语义–运动掩码与 keyframe 遮挡补全。未见已核实官方代码 URL；arXiv 页面未标注接收信息（有二手来源称 IROS 接收，**未能核实，不采信**）。
- **阅读程度**：【摘要+部分章节】，非全文。实际读了：摘要、方法概述、表 I–V、结论；两栏混排导致部分定性图旁文字交错，数字以表行为准；未通读全部参考文献与全部定性图说明。

#### 2. MonoVoc: Decoupling Geometry and Semantics for Lightweight Monocular Open-Vocabulary 3D Gaussians【摘要+部分章节】
- 链接：https://arxiv.org/abs/2607.28300 （PDF：https://arxiv.org/pdf/2607.28300）
- 学科类别（arXiv 页面）：主类 cs.CV，交叉 cs.AI；当前 v1
- 提交日期：2026-07-30（cs；早于近 2–3 周范围，已注明真实日期；② 方向 9 月下旬可核实的开放词汇 3DGS 新论文偏少，故收录）
- 作者：Pouya Ardehkhani, Zahra Dehghanian, Morteza Abolghasemi, Hamid R. Rabiee（Sharif University of Technology）
- **方向归属**：② 开放词汇和大模型驱动的语义地图（训练无关的单目开放词汇物体级语义高斯图；几何由 HI-SLAM2 先建，语义后处理挂接；**非**在线多传感器融合占用）。
- **要解决的问题**：开放词汇 3DGS 常纠缠多视图采集、逐场景优化与稠密语言特征显存；单目场景下语义与重建耦合导致地图重、难编辑。
- **方法**：训练无关四阶段——(1) HI-SLAM2 单目重建几何高斯；(2) Semantic Color Deblending（SCD）反推 alpha 混合后的语义色；(3) Lab 空间 CMC 距离调色板量化得物体身份；(4) 每物体挂一份 CLIP / Perception Encoder 嵌入，避免每高斯存高维语言特征。硬件叙述：单卡 A100。
- **实验数据**：Replica（单目 RGB + 2D 分割监督语义后处理）；对比 ObjectGS、SceneSplat。
- **作者自报关键数字**（对照 PDF 表 1–4 与 Limitations）：
  - 表 1 Replica：PSNR / SSIM / LPIPS / mIoU = **41.91±0.34 / 0.981±0.0012 / 0.025±0.0016 / 91.22±0.72%**（SceneSplat mIoU 91.89±0.84% 略高；Ours PSNR/LPIPS 最优段）。
  - 表 2 量化距离：CMC 非白像素错误率 **7.48±0.12%**（低于 CIEDE2000 的 7.74%、RGB 的 7.83%）。
  - 表 3 文本检索（15 queries）：Perception Encoder + soft mask Top-1 / Top-3 **80.0±5.0% / 86.7±3.6%**。
  - 表 4 效率：#Gaussians / Memory / Runtime = **140K / 14 MB / 81±17 min**（ObjectGS 1M / 90 MB / 186±34 min；SceneSplat 1.5M / 149 MB / 40±22 min\*且\*不含建图）。
- **作者承认的局限 / 边界**：调色板量化在相近语义色或中间色时歧义；SCD 为逐高斯近似而非全局反问题，边界/高重叠区可能出错。未见已核实官方代码 URL。
- **阅读程度**：【摘要+部分章节】，非全文。实际读了：摘要、方法管线、表 1–4、Discussion and Limitations、结论；未通读全部附录 C/D 与全部消融噪声实验细节。

#### 3. Gau-Occ: Geometry-Completed Gaussians for Multi-Modal 3D Occupancy Prediction【摘要+部分章节】
- 链接：https://arxiv.org/abs/2603.22852 （PDF：https://arxiv.org/pdf/2603.22852）；CVPR 2026 Open Access 页可打开：https://openaccess.thecvf.com/content/CVPR2026/html/Lv_Gau-Occ_Geometry-Completed_Gaussians_for_Multi-Modal_3D_Occupancy_Prediction_CVPR_2026_paper.html
- 学科类别（arXiv 页面）：cs.CV；当前 v1
- 提交日期：2026-03-24（cs；早于近 2–3 周范围，已注明真实日期；③ 方向近期可核实的新论文不足，故收录）
- 作者：Chengxin Lv, Yihui Li, Hongyu Yang, YunHong Wang
- **方向归属**：③ 多传感器融合感知（LiDAR + 多相机语义占用；以语义 3D 高斯锚点替代稠密体素/BEV 张量）。
- **要解决的问题**：多模态占用依赖昂贵稠密体素/BEV；稀疏 LiDAR 几何不完整导致远距/遮挡区空洞。
- **方法**：Gau-Occ——(1) LiDAR Completion Diffuser（LCD）补全稀疏点云并初始化密度感知高斯锚；(2) Gaussian Anchor Fusion（GAF）：Geometry-Guided Sampling + Geo-VLAD Resampling，几何对齐地采样多视图图像特征并跨模态聚合；(3) 高斯精炼后 splat 到体素得稠密语义占用。训练/推理叙述：nuScenes 用 RTX 4090；KITTI-360 用 A100。
- **实验数据**：SurroundOcc-nuScenes、Occ3D-nuScenes、KITTI-360；对比 DAOcc、Co-Occ、OccMamba、SDGOcc、GaussianFormer-2 等。
- **作者自报关键数字**（对照 PDF 表 1–5 / 效率表）：
  - 表 1 SurroundOcc-nuScenes：Ours（L+C）IoU / mIoU **44.3 / 32.7**（DAOcc 42.8 / 32.1；Co-Occ 41.1 / 27.1）。
  - 表 2 Occ3D-nuScenes：Ours mIoU **55.1**（DAOcc 54.3；SDGOCC 51.7）。
  - 表 3a 消融：Full（P′ + DS+RS）**44.3 / 32.7**；原始 LiDAR P **41.5 / 29.6**；仅 RS 初始化 **43.9 / 32.4**。
  - 效率表（RTX 4090, bs=1）：25.6k queries 时 Lat./Mem./IoU/mIoU **230 ms / 5.4 GB / 44.3 / 32.7**；12.8k queries **124 ms / 3.3 GB / 42.4 / 31.5**（对照 DAOcc 291 ms / 8.6 GB / 42.8 / 32.1；Co-Occ 595 ms / 12.1 GB）。
  - 补充表 KITTI-360：Ours（L+C）IoU / mIoU **58.9 / 25.8**（表 5 行首两项；逐类列未逐格全核）。
- **作者承认的局限 / 边界**：正文未见独立 Limitations 小节；结论强调稀疏高斯相对稠密查询的效率。未见已核实官方代码仓库 URL。
- **阅读程度**：【摘要+部分章节】，非全文。实际读了：摘要、方法要点、表 1–3、效率表、结论；KITTI-360 逐类列与全部定性图未逐格核对。

### 6.2 选题 1 摘要

- **一句话**：以 LiDAR 里程计/配准保户外跟踪，在 3D 高斯上在线挂接开放词汇语言特征场，用 LiDAR 距离/高度几何约束语言嵌入的多视角证据累积，以抑制细结构（杆、树干、交通标志、围栏）的标签错投；在 SemanticKITTI 与校内半户外实采上评测。
- **与最接近工作 ArborSplat 的差异**：ArborSplat 的地图存固定 6 类语义 logit，评测限固定 6 类、场景限果园（其前端用文本提示的分割模型，不能称其「闭集」）；本题是可任意文本查询的语言特征场。
- **创新点与强度**：(1) 户外 LiDAR 地图上的连续语言特征场——组合式新意，单独不构成算法贡献；(2) LiDAR 条件化的证据门控，写成可证伪假设：相对「无门控」与「仅可见性门控」，在细结构子集上有稳定提升，若消融不显著则退化为「系统 + 评测协议」；(3) 评测协议属评测设计，不算方法创新。整体创新强度中等偏弱。
- **骨干**：2607.04127（LiDAR-only、2D 高斯地图、含回环、MIT 许可证，README 与许可证已读，未编译运行）。它没有相机颜色/特征渲染，需自行新增相机外参标定、透视光栅化、特征渲染（约 3 个月，估计）；且其地图会回馈跟踪，接入语言特征时不能破坏该路径。
- **评测协议**：SemanticKITTI 序列 08 上的 3D 逐点开放词汇 mIoU（同时报裸类名与加模板两套）、细结构子集 IoU、词表外查询小规模标注、校内半户外定性；对照 ArborSplat（设定不同，仅作参考）、适配版 OLS/LEGO/LatentAM、可见性门控式聚合基线。
- **周期**：约 17–20 个月，为顾问估计，需与导师确认；设有检查点与降级方案（门控无增益时降为「系统 + 评测协议」）。
- **暂定阈值**：骨干相机扩展的检查点暂定为留出帧渲染 PSNR ≥ 20 dB；「加/不加特征通道」的 ATE 相差超过 5% 视为异常。两者均为暂定经验值，未经试跑，需与导师重新确认。
- **主要风险**：KITTI 彩图仅 1226×370，细结构在图中像素占比小（顾问对序列 08 的自行统计，非文献数字：每 10 cm 物理宽度在中位深度约占 5–7 像素；pole、trunk 的真实直径没有数据，“几像素宽”只能部分确认），细结构 IoU 可能主要受 2D 特征分辨率限制；组内无开放词汇先例；成均馆大学（SKKU）的 LAIR 实验室同时拥有 LEGO-SLAM 与 2607.04127，存在合并成直接竞争的可能（推断，非已知事实）。
